# Замена 3D-модели

1. Положите модель GLB сюда, например `public/models/heritage.glb`.
2. В `src/config/experience.ts` измените `modelUrl: null` на `modelUrl: '/models/heritage.glb'`.
3. При необходимости задайте начальный поворот `rotation: [x, y, z]` в радианах.

Модель автоматически центрируется и вписывается в сцену. Предпочтителен GLB со встроенными текстурами, до 5 МБ и без Draco/KTX-сжатия (декодеры не подключены). Проверьте права на модель и добавьте источник в титры.

Сейчас показывается процедурная декоративная композиция, а не реконструкция исторического предмета. При ошибке загрузки или отсутствии WebGL доступно статичное представление. Сцена загружается отдельным модулем; движение приостанавливается вне экрана, в скрытой вкладке и при системной настройке reduced motion. Кнопки поворота доступны с клавиатуры.
