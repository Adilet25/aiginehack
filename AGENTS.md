# Codex Instructions

Before making changes, read PROJECT.md.

## Development Rules

- Inspect the existing code before changing anything.
- Preserve existing functionality unless explicitly asked to remove it.
- Do not rewrite working components unnecessarily.
- Use React + TypeScript.
- Follow the existing project architecture.
- Create reusable components.
- Keep the website responsive.
- Support KG / RU / EN localization.
- Do not invent cultural or historical information.
- Do not invent sacred places or coordinates.
- Clearly label mock/prototype functionality.
- Run the project and check for errors after significant changes.
- Fix TypeScript/build errors caused by your changes.

## Design

Follow the design direction described in PROJECT.md.

The overall website should feel like:

- an immersive digital museum;
- modern Kyrgyz cultural storytelling;
- premium editorial design.

Avoid turning the entire website into:

- a gaming dashboard;
- cyberpunk UI;
- generic SaaS;
- crypto-style interface.

Gamification should be used primarily inside interactive features.

## Working Process

For large tasks:

1. Inspect relevant files.
2. Understand existing implementation.
3. Explain the planned changes.
4. Implement them.
5. Run checks/build.
6. Fix errors.
7. Summarize what was changed.

Do not delete or replace major functionality without permission.
