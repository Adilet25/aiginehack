# Айгине · локальный сайт

Запуск из папки проекта.

```powershell
npm.cmd run dev
```

Откройте http://127.0.0.1:4173. Установка зависимостей не нужна. При занятом порте можно задать переменную среды PORT.

- Нажмите на юрту, кнопку входа или прокрутите вниз. Камера приближается к дверям и входит внутрь. Снаружи используется покрашенная модель из models/yurt-painted.glb. Для прохода через двери и интерьера используется отдельная 3D-сцена.
- Календарь ведёт через түндүк к 3D-Луне на звёздном фоне. Нажатие запускает сближение Луны с Үркөр и счётчик дней. После сцены открываются пояснение, 12 традиционных месяцев по Жумаеву и обычный календарь. Кнопка «Музыка» управляет звуком.
- Камень ведёт к вращаемой 3D-иллюстрации. Модель можно приближать и отдалять.
- На карте доступны Сулайман-Тоо, Манжылы-Ата и Абшыр-Ата. Добавьте места и выберите порядок остановок. Карта покажет автомобильный маршрут, километраж каждого участка, общую длину и примерное время. Маршрут до Абшыр-Ата заканчивается у дорожного подъезда перед водопадом.
- Доступны кыргызский, русский и английский. Системная настройка уменьшения движения отключает переходы камеры. При отсутствии WebGL остаются иллюстрации и обычная навигация.

Three.js 0.186.1 включён с лицензией MIT в dist/vendor. Фото Сулайман-Тоо: Hzewo, CC BY-SA 4.0. Фото Чолпон-Аты: Bernard Gagnon, CC0. Ссылки на источники доступны в интерфейсе. Внешняя модель весит около 56 МБ.

Карта использует Leaflet 1.9.4, локальные контуры Natural Earth и растровый слой OpenStreetMap при приближении. Шесть направленных автомобильных участков для трёх объектов сохранены в assets/atlas-roads.json. OSRM построил их по данным OpenStreetMap 17 ноября 2026 года. Карта соединяет участки в порядке остановок. Оценки времени используют модель OSRM и не учитывают текущие заторы или перекрытия.
